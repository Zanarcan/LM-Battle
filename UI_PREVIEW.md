# 🎮 ART Project - Battle Arena UI Preview

## 🌟 Vista General del Dashboard

El Battle Arena UI es una interfaz visual épica diseñada con tema cyberpunk para batallas LLM vs LLM en tiempo real.

---

## 📱 Estructura de la Interfaz

### Header Principal
```
⚔️ ART PROJECT ⚔️
ADVERSARIAL RED TEAM BATTLE ARENA
🤖 LLM vs LLM • Real-time Attack & Defense • Cyberpunk Edition 🤖
```

- Fuente: **Orbitron 900** con animación glow pulsante
- Colores: Gradiente cyan (#00f5ff) → magenta (#ff00ea)
- Efecto: Text shadow animado en loop

## ✨ Animaciones y Efectos

### Glow Pulsante
```css
@keyframes glow {
  from: text-shadow: 0 0 10px cyan
  to:   text-shadow: 0 0 40px magenta
}
```

### Hover Transform
```css
.battle-card:hover {
  transform: translateY(-5px);
  border-color: magenta;
  box-shadow: 0 8px 32px magenta;
}
```

### Progress Bar
```
[████████████████░░░░░░░░░░] 60%
 ^ Gradiente cyan → magenta animado

```

### Tablet (768-1200px)
- Sidebar colapsable
- Cards en columna única
- Gráficos full width

### Mobile (<768px)
- Sidebar overlay
- Cards stacked
- Métricas en grid 2x2

## 🚀 Performance

### Tiempos de Carga
- Initial load: <2s
- Chart render: <500ms
- Battle round: 2-5s (depende de LLM)

### Optimizaciones
- Pre-computed embeddings
- Lazy loading de tabs
- Session state caching
- Plotly express para gráficos rápidos

## 🎯 UX Features

### Feedback Visual
- ✅ Success toasts (verde)
- ❌ Error alerts (rojo)
- ⚠️ Warning messages (amarillo)
- ℹ️ Info boxes (cyan)

### Interactive Elements
- Hover tooltips en gráficos
- Expandable sections
- Drag-to-zoom en charts
- Click to export

### Accessibility
- High contrast colors
- Clear font sizes (14-20px)
- Descriptive labels
- Keyboard navigation
